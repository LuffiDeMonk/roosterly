# Frontend – TanStack Start + Router & shadcn/ui

Frontend for Roosterly built with **React 19**, **TanStack Start**, **TanStack Router**, **Tailwind CSS v4**, and **shadcn/ui** with **TypeScript**.

---

## 🧱 Tech Stack

- **React 19**
- **TanStack Start** (Fullstack / SSR)
- **TanStack Router** (Type-safe file-based routing)
- **shadcn/ui** (Accessible, customizable UI components)
- **Tailwind CSS v4** (Utility-first styling with `@tailwindcss/vite`)
- **Vite 8** (Fast build tool & dev server)
- **TypeScript**

---

## 🚀 Scripts

- `npm run dev`: Start the Vite dev server with TanStack Start SSR & Hot Module Replacement
- `npm run build`: Type-check with `tsc -b` and build production client and server bundles
- `npm run lint`: Lint code with ESLint and `typescript-eslint`
- `npm run preview`: Preview the production SSR build locally
